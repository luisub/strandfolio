# Strandfolio example records

In Sequence, **Open design example** opens [pReporter_demo.gb](pReporter_demo.gb). The PCR tab uses the active document. The linear [Insert_demo.gb](Insert_demo.gb) and its [reference values](insert_demo_tm.json) are bundled validation fixtures.

## Synthetic binary .dna input

`synthetic_circular.dna` is an original, deliberately small binary fixture authored for strandfolio. Its sequence and annotations are artificial and contain no user material or third-party sequence. It is covered by the repository's [BSD 3-Clause License](../../../LICENSE). It is not a SnapGene-produced file and does not validate every SnapGene version.

- Size: 1,487 bytes.
- SHA-256: `d061518baa205ae816675b88026701739ba5bf8bff1edddba146fe04c567218a`.
- DNA: `AACCGGTTAAATGCGTACGATTCCGGAATTCAGTACGTAA` (40 letters, circular).
- Notes: accession `synthetic.circular`, comments `Synthetic_plasmid independent fixture`, type `Synthetic`, last modified `2026.11.16`.

Each binary packet has a one-byte type and a four-byte unsigned big-endian payload length. In order: cookie `0x09` with `struct.pack('>8sHHH', b'SnapGene', 1, 1, 1)`; DNA `0x00` with flag byte `0x01` followed by the ASCII sequence; Notes XML `0x06`; Features XML `0x0A`; Primers XML `0x05`; opaque `0x7F` with bytes `opaque fixture metadata`. The opaque packet exercises the fidelity warning without assigning it a biological meaning.

The feature expectations below are hand-specified, not generated by the parser under test. Internal intervals exclude the upper endpoint; compound parts remain in biological traversal order as supplied by Biopython for these cases.

| Label | XML ranges / directionality | Expected zero-based parts | Strand | Expected extracted letters |
| --- | --- | --- | --- | --- |
| reverse CDS | `5-13` / `2` | `[4,13)` | −1 | `CATTTAACC` |
| origin wrap | `37-4` / `1` | `[36,40)`, `[0,4)` | +1 | `GTAAAACC` |
| reverse multipart | `3-5`, `16-18` / `2` | `[15,18)`, `[2,5)` | −1 | `GTACGG` |
| synthetic primer | binding location `3-8`, bound strand `0` | `[3,9)` | +1 | `CGGTTA` |

The CDS has `codon_start` integer `1`, translation text `EXAMPLE`, and note `Synthetic reverse feature`. That deliberately nonbiological translation is preserved as imported text, never presented as a computed result. All Feature segments use type `standard`; the other two features use type `misc_feature`.

The primer packet sets minimum continuous match length `5` and melting temperature `40`. It contains one accepted binding (`3-8`, annealed bases `CGGTTA`, temperature `50`), a simplified duplicate of that binding, one short binding (`20-22`, annealed bases `GGA`, temperature `50`), and one cold binding (`25-30`, annealed bases `CGGTTA`, temperature `20`, reverse strand). Biopython 1.88 yields one `primer_bind` entry after filtering. The primer's sequence and description XML attributes are deliberately present but are not exposed by that parser; the import warnings explain this limitation.

The test module also constructs tiny malformed inputs and a reverse-origin example in temporary directories. Biopython 1.88 can preserve a reverse origin-crossing feature's parts in an order that is unsuitable for whole-feature biological extraction. That case checks the warning and preservation of parser output rather than claiming extraction fidelity.
